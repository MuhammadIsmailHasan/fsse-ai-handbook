::::placement{id="modules/m2/w4"}
You built RevoShop with these tools. Can you explain them without looking?

:::quiz
1 · Why use an application factory (`create_app()`) instead of a global `app = Flask(__name__)`?

It lets you create apps with different configs (dev, test, prod), avoids import-time side effects and circular imports (extensions are initialized with `init_app`), and gives each test a fresh app.
:::

:::quiz
2 · What's a Flask blueprint, and what problem does it solve?

A group of routes (plus error handlers/hooks) that can be registered on an app, often with a URL prefix. It splits a large app into feature modules (auth, products, orders) instead of one huge file.
:::

:::quiz
3 · In SQLAlchemy 2.0, how do you load all applications for user 7 ordered by newest, and what's a `Session`?

```python
stmt = select(Application).where(Application.user_id == 7).order_by(Application.created_at.desc())
applications = db.session.scalars(stmt).all()
```

The session is a unit of work: it tracks loaded/changed objects and sends changes to the database in a transaction on `commit()`.
:::

:::quiz
4 · You add a `NOT NULL` column to a table with 2 million rows in production. How do you migrate safely?

Expand/contract: add the column as **nullable** (or with a default), deploy code that writes it, **backfill** existing rows (in batches), then add `NOT NULL` in a later migration. Review autogenerated migrations and test `upgrade` and `downgrade`.
:::

:::quiz
5 · What's the N+1 query problem and how do you fix it in SQLAlchemy?

Loading N parents with one query, then triggering one extra query per parent when accessing a relationship (N more). Fix with eager loading: `select(User).options(selectinload(User.applications))` (or `joinedload` for many-to-one).
:::

:::quiz
6 · Where should the rule "an application's status can only move forward" live: route, service, repository or model?

In the service/domain layer (possibly a model method), backed by database constraints — not in the route (HTTP only) or repository (data access only).
:::
