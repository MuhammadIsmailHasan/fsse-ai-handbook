# Module 3 · W3 · Flask or FastAPI?

> 🚫🤖 **No-AI** · ⏱️ ~20 min

A decision guide is a set of rules. Write them as code. In `framework_choice.py`, implement `choose_framework(...)` — it returns `"flask"`, `"keep-flask"` or `"fastapi"`.

The three rules (page templates → Flask; existing app with no reason to move → keep it; otherwise a score with a migration penalty) are written at the top of the file.

cd exercises
uv run pytest m3/w3/04-decision
