# DSA · Stage 1 · Recursive Basics

> 🟢 Easy · No loops allowed

| Function | Example | Result |
|---|---|---|
| `sum_digits(n)` | `4071` | `12` |
| `power(base, exp)` | `2, 10` | `1024` |
| `is_palindrome(text)` | `"racecar"` | `True` |
| `count_down(n)` | `3` | `[3, 2, 1, 0]` |

`n` and `exp` are ≥ 0. `is_palindrome` is case-sensitive and uses the text as-is.
